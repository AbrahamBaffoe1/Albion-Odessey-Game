# Game direction

Cosmic Squirrels: Albion Odyssey blends campus discovery with an imaginative legacy that every player can shape. The real Albion campus provides the shared point of reference; the Legacy Campus gives players authorship over a personal world.

## Two ways to discover

**Room play:** explore a virtual campus from a desk, sofa, or accessible seated setup. Complete the full educational collection without location permission. The prototype implements virtual camera exploration and collection on the construction island; a separate surveyed exploration map is future work.

**Campus play:** an opt-in mobile layer turns approved public campus locations into discovery points. GPS can suggest proximity, with AR used for a reveal after the player stops. The collection and building economy is shared with room play. This is a future mode; the current source includes only a tested location-eligibility policy, not a device adapter or camera overlay.

Neither mode should require an exclusive reward that makes the other mode second-class. Physical presence can change presentation, not access to core progression.

## Two visual appearances

**Campus:** recognizable Albion building silhouettes and materials, ultimately based on surveyed references. The first kit explores brick, stone, and copper using original stylized models.

**Echo Fantasy:** reinterpret the same landmarks through cosmic squirrels, celestial observatories, floating memory lights, and purple/gold architecture. Players change appearance without losing their construction or collection.

## Personal and shared creation

Every Keeper has an independent campus, inventory, journal, and appearance. Building is reversible and refunds all acorns. The current prototype offers four local profiles with shared-device turn taking.

A shared Constellation Beacon records contributions separately from personal buildings. Online expansion should carry this same distinction into authenticated player islands and a server-owned community campus. Switching a local profile is never treated as online identity.

## Features implemented in prototype source

- Twelve collectible memory echoes, individually collectable by each local Keeper.
- Four modular building types and a 7×7 personal construction grid.
- Campus / fantasy appearance per profile.
- Full-refund reclamation for easy redesign.
- A collective 24-acorn Beacon with contributor accounting.
- A journal that distinguishes campus references from fiction.
- Three guided progression stages and local persistence.

## Creative features planned

- **Era windows:** compare an archive-supported past view, today's campus, and the player's fantasy future at the same landmark.
- **Squirrel companion:** a character that points toward undiscovered memories; it can offer optional hints without inventing college history.
- **Memory trails:** students author routes and stories through a reviewed creator workflow. Unpublished drafts stay private.
- **Room-scale Legacy Campus:** place a miniature island on a desk with AR, with the same actions available through standard controls.
- **Constellation festivals:** collective construction unlocks temporary visual celebrations, with contributions capped to avoid endless grinding.
- **Blueprint postcards:** export/import bounded building layouts after validation, then add a curated showcase for community designs.
- **Seasonal ecology:** gardens change with the chosen visual season; planting choices can trigger source-backed campus ecology quests.
- **Accessible discovery:** adjustable text, reduced motion, remappable controls, controller/touch input, and equivalent seated routes.

These are design commitments for future milestones, not claims of completed features.
