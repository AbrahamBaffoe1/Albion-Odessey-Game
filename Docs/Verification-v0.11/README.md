# 0.11 verification

The 0.11 player was built with Unity 6000.6.0f1 for macOS after adding the four-wing Science Complex, campus life layer, accessibility controls, LAN session foundation, XR bridge, schedule fields, save recovery and runtime profiling. The release archive is ad-hoc signed for local macOS testing; production Developer ID signing and notarization remain environment-dependent.

The five existing release suites all exited successfully. The focused walkable-building smoke test also passed for Robinson, Bonta and Science Complex. The Science Complex is game-scale reconstruction geometry: its wing proportions, room contents and exact measurements remain tunable art data rather than a surveyed digital twin.

See `release-checks.json` and `walkable-building.json` for the machine-readable results.
